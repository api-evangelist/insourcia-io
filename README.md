Insourcia provides private market intelligence for AI agents, offering a searchable database of over 29.8 million companies, their financials, directors, and legal announcements. Users can query company data, receive structured results, and integrate the service via a REST API for automated workflows. The platform includes tools for risk assessment, acquisition targeting, and market monitoring, with documentation, pricing, and demo options available on its website.

**Areas:** Private Market Intelligence · AI Integration · Financial Data · Company Search · Risk Assessment

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Insourcia: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
